# Korea City Gas Efficiency Dashboard

대한민국 도시가스 **수요가수(계량기 수)**, **공급량(판매량)**, **배관길이**를 기반으로  
회사/지역 단위 효율성 지표를 분석하는 Streamlit 대시보드입니다.

- 데이터 출처: [한국도시가스협회 통계](http://www.citygas.or.kr/info/stats/index.jsp?sbranch_fk=2)
- 주요 분석 지표:
  - 수요가수 (실제 요금 청구 계량기 수)
  - 공급량 (판매량, m³ 기준)
  - 배관길이 (공급관 + 본관)
  - 공급량 / 수요가수 (m³/계좌)
  - 공급량 / 배관길이 (m³/m)
  - 수요가수 / 배관길이 (계좌/m)

---

## 📊 주요 기능

1. **그룹 기준 전환**
   - `회사` 기준 분석
   - `지역(시도)` 기준 분석
   - 회사 기준일 때는 지역 전체 사용,  
     지역 기준일 때는 회사 전체 사용 (서로 배타적 필터)

2. **효율성 지표 시각화 (6개 그래프)**
   1. 수요가수 추이
   2. 공급량 추이 (단위: m³ / 천 m³ 선택 가능)
   3. 배관길이 추이
   4. 공급량 / 수요가수
   5. 공급량 / 배관길이
   6. 수요가수 / 배관길이

3. **필터 기능**
   - 그룹 기준: `회사` / `지역(시도)`
   - 공급량 단위: `m³` / `천 m³`
   - 연도 범위 슬라이더 (기본 2001년부터)
   - 회사/지역 멀티셀렉트
   - 상품 멀티셀렉트  
     → 상품 선택은 **수요가수·공급량에만 영향**,  
        배관길이는 실제 물리 길이라 상품과 무관

4. **하이라이트**
   - 그룹 기준이 `회사`일 때: **대성** 라인 강조
   - 그룹 기준이 `지역(시도)`일 때: **대구** 라인 강조

5. **집계 데이터 & 엑셀 다운로드**
   - 화면 하단에서 집계 테이블을 토글로 열어보기
   - 그래프별 데이터를 시트로 나눈 **엑셀 파일 다운로드**
     - `01_수요가수`
     - `02_공급량_m3`
     - `03_배관길이_m`
     - `04_공급량_수요가수비`
     - `05_공급량_배관길이비`
     - `06_수요가수_배관길이비`
